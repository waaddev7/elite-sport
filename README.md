# 🏋️ Elite Sport

Elite Sport is a full-stack fitness and sports e-commerce web application that combines online shopping, fitness progress tracking, and AI-powered training assistance in one platform.

The project was built to provide users with an interactive fitness experience where they can explore sports products, manage their cart, track their progress, and generate personalized fitness plans using artificial intelligence.

## 🚀 Running the Project Locally

1. Clone the repository:

```bash
git clone https://github.com/waaddev7/elite-sport.git
```

2. Navigate to the project directory:

```bash
cd elite-sport
```

3. Install the backend dependencies from the backend directory:

```bash
npm install
```

4. Configure the required environment variables.

5. Start the backend server.

6. Open the frontend in your browser.

---

## 🔒 Environment Variables

Sensitive information such as API keys, database credentials, and authentication secrets should be stored in environment variables and must not be committed to the repository.
